# Design System Prompt

## Use

Load this skill only for explicit design work. Do not use it for ordinary coding,
review, cleanup, filesystem, or reconnaissance tasks.

## Workflow

1. Read `skills/system-prompt.md` for the design operating instructions.
2. If the request matches a procedure listed in that prompt's skills section,
   read the matching file under `skills/`.
3. Follow the procedure in the current project context, using existing design
   systems, screenshots, code, and assets before inventing a new visual language.
4. Verify rendered UI with an actual browser or screenshot workflow when the
   output is visual.
